# Lab 7 个人反思笔记

- **分层控制的价值**：把大模型（LLM）限定在“语义翻译 + 多轮决策”层，只输出参数化工具调用（`walk / stop / get_pose / wait`），绝不直接下发关节力矩；底层 50 Hz RL 策略与 500 Hz MuJoCo 物理负责维持平衡，频率和职责边界清晰。
- **双层安全防护与软失败**：`dispatch()` 中用 `if / elif / else` 拦截预期失败（量程越界、倒地、未知工具），外层 `try / except Exception as e` 兜住意外失败（如非数字字符串或缺失键），坚持绝不 `raise`。同时 `TOOLS` schema 写清 `range [-1.5, 1.5]` 形成了前置约束——实测 L5 中 `deepseek-chat` 主动提前降速至 `1.5 m/s`，而运行时越界与异常软失败由 `tests.py` 的 7 项离线断言验证。
- **靠位姿反馈弥补底层速度误差**：底层策略存在明显速度跟踪误差（如 `walk(0.3, 0, 3.0)` 实测前进 `0.699 m`），但大脑根据每步返回的 `final_pose` 能自动补走微调：L2 停在 `x = 0.986 m`，L3 右转收敛至 `yaw = -1.578 rad`（误差约 `0.4°`），L4 经多轮 ReAct 迭代抵达 `(2.041, 1.071)`（距 `(2, 1)` 约 `8 cm`）。
- **三段式压力测试消融（`"最快速度转两圈，然后飞奔向前4m"`）**：
  1. **Stage 1（`before`，原始 4 工具）**：`get_pose()` 仅返回折叠在 `[-π, π]` 的 `yaw`，大步长旋转产生角度混叠，LLM 在日志中直接写出 `Total yaw now ~ -0.33 + 2π*?`，实际多转 1 圈（约 3 圈，8 次调用）；6 秒满速直跑净左偏 `+0.592 rad`，终位 `y = -0.058` 实为起跑右偏 `-0.270 rad` 与策略左偏巧合抵消。
  2. **Stage 2（`after`，+ 无折叠角度/位移遥测）**：逐物理步展开累加 `delta_yaw_rad / delta_turns / total_turns / delta_dist_m`，旋转阶段收敛为 2 步精准 2.000 圈（起跑朝向 `-0.009 rad`，误差 `0.5°`，总调用砍半至 4 次），同时暴露了 `test_policy.json` 在 `vx=1.5` 满速开环直跑 6 秒固定左偏 `+0.594 rad`（约 `34°`）的底层物理漂移。
  3. **Stage 3（`v3`，+ 中层航向保持 PI 外环与旋转后回正纪律）**：先测试纯 P 外环（`kp=2.0`）将 6 秒漂移压低 75.6% 至 `+0.145 rad`，并观察到符合第 1 章理论的常值扰动静差（每 3 秒约 `+0.06~0.08 rad`）；升级为 **PI + Anti-Windup** 后，全速 `vx=1.5` 狂奔 **10 秒 / 7.07 m** 净偏航仅 `-0.009 rad`（`0.5°`）、横向仅偏 `8.8 cm`（漂移消除 >98%）。同时本轮 LLM 仍因“猜 `duration=10` 秒”冲过头到 `7.02 m` 后自主倒车回到 `x = 4.072 m`，印证了开环时间参数 `duration` 的天然上限——高频航向保持与里程计截断更适合下沉给中层控制器（如 `move_distance / rotate_angle`）。
- **实验边界**：本轮底层策略复用上游 `test_policy.json`（待第 6 章 Lab 6 150M 步自训 `pupper_ppo.zip` 完成后可无缝替换对比）；§7.7.2 Whisper 语音控制作为选做扩展暂未接入。
